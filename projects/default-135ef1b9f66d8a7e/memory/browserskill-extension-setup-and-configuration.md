# BrowserSkill (Edge 扩展) 安装配置与系统换机恢复指南

本指南记录了在**系统重装、换机迁移或全新部署**环境时，Microsoft Edge 浏览器与 **BrowserSkill**（腾讯开源浏览器自动化套件）扩展的核心配置规范与防坑要点，确保跨 Agent 协同与浏览器自动化开箱即用。

---

## 一、核心架构与依赖组件

BrowserSkill 依靠 **本地守护进程 + 浏览器官方扩展** 协同工作：
1. **本地 CLI / 守护进程**：`bsk`（0.3.0+），后台守护进程常驻监听本地 `ws://127.0.0.1:52800`；
2. **Edge 浏览器扩展**：Edge Add-ons 官方商店安装的 **BrowserSkill** 扩展（版本 0.3.0+，实例 ID 自动分配）；
3. **工作机制**：扩展通过本地 WebSocket 握手直连 `bsk daemon`，复用用户已登录的浏览器会话与 Cookie，免除传统 CDP 自动化对 Chromium 144+ 弹出的安全警告。

---

## 二、换机/全新系统初始化必配项（配置清单）

重装系统或换机后，在 Edge 扩展管理中安装 BrowserSkill，点击扩展图标打开弹窗控制面板，必须核查并完成以下四项配置：

### 1. 扩展连接开关：保持开启 (`READY`)
- **位置**：扩展弹窗顶部第一张卡片；
- **配置**：主拨动开关保持开启（橙色），连接通道指向 `本机 · ws://127.0.0.1:52800`，状态显示绿点 `已连接 READY`。

### 2. 「借用标签页前确认」：必须彻底关闭 (`OFF`) ⚠️【核心关键项】
- **位置**：扩展弹窗 -> **【自动化设置】**卡片 -> **【借用标签页前确认】**；
- **配置**：**必须关闭（滑块置于左侧，灰色）**；
- **关闭原因与技术原理**：
  - **若开启**：每当 Agent 需要接管、复用用户当前手动打开的标签页（User Tab，例如 Arena AI、ChatGPT 或正在调试的 Web 页面）时，Edge 浏览器会**强制弹出拦截对话框打扰用户**，必须人工点击“允许”；若未及时点击，Agent 会陷入 60 秒等待挂起甚至报错超时；
  - **关闭后**：Agent 即可**完全静默、无感地直接借用和复用已有标签页**，无需每次打断用户手头工作去点确认，自动化与代码审查对拍极其丝滑。

### 3. 「允许请求人工协助」：保持开启 (`ON`)
- **位置**：扩展弹窗 -> **【自动化设置】**卡片 -> **【允许请求人工协助】**；
- **配置**：保持开启（橙色）；
- **作用**：当自动化任务遇到极端风控、Cloudflare 强盾、图形验证码（CAPTCHA）或短信 OTP 登录时，允许 Agent 向终端发起协助请求，由人工干预解卡后继续执行。

### 4. 「控制提示」：按需开启
- **位置**：扩展弹窗 -> **【控制提示】**卡片；
- **作用**：开启后，被控标签页上方会显示小巧横幅，提示当前页面处于自动化接管中，防止误触。

## 三、日常运行与排障要点 (Gotchas)

1. **`no browser is currently connected` 报错排查**：
   - **根因**：Edge 浏览器尚未启动或已被彻底关闭退出。扩展仅在 Edge 进程存活时运行；
   - **解决办法**：日常保持 Edge 浏览器开启（可最小化至任务栏或后台常驻）。若未启动，Agent 在 Windows 下可通过 `start msedge` 直接唤醒。
2. **标签页与 Session 常驻复用铁律 (Persistent Tab Invariant)**：
   - 在开发与多轮审查会话期间，**严禁频繁调用 `bsk session stop` 关闭会话或标签页**；
   - 全程维持 WebSocket 热连接与页面 DOM 树，避免重复建立握手与 SPA 加载时延；
   - 仅在整个多步骤任务彻底交付收口且确认无后续需求时，才在最后统一调用 `session stop` 释放句柄。
